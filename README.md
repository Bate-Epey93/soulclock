# SoulClock — Manifestor Work Timer

## Quick Deploy to Your Phone (Free, ~5 Minutes)

### Step 1: Create a GitHub account (if you don't have one)
Go to https://github.com and sign up.

### Step 2: Create a new repository
1. Click the **+** icon (top right) → **New repository**
2. Name it: `soulclock`
3. Make it **Public**
4. Click **Create repository**

### Step 3: Upload the files
1. Click **"uploading an existing file"** on the new repo page
2. Drag in ALL these files:
   - `index.html`
   - `manifest.json`
   - `sw.js`
   - `icon-192.svg`
   - `icon-512.svg`
3. Click **Commit changes**

### Step 4: Enable GitHub Pages
1. Go to **Settings** → **Pages** (left sidebar)
2. Under "Source", select **Deploy from a branch**
3. Branch: **main**, folder: **/ (root)**
4. Click **Save**
5. Wait 1-2 minutes

### Step 5: Install on your phone
1. Open `https://YOUR-USERNAME.github.io/soulclock/` on your phone browser
2. **Android (Chrome):** Tap the three-dot menu → "Install app" or "Add to Home Screen"
3. **iPhone (Safari):** Tap the share icon (box with arrow) → "Add to Home Screen"
4. The app now lives on your home screen like a native app

## Updating
To update the app, just replace files in your GitHub repo. GitHub Pages will redeploy automatically. Users may need to refresh once to get the new version.
